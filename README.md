# IMX Portfolio

Personal portfolio for **Imran Noori (IMX)** — full-stack developer & computer instructor.

Built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Edit site copy, projects, and links in `src/lib/site.ts`.
Replace the profile photo at `public/images/imran.jpg`.

## Deploy

Deploy to [Vercel](https://vercel.com) — connect the repo and ship.
